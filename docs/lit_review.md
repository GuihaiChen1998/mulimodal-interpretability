## [12] MICLIP: Learning to Interpret Representation in Vision Models（ICLR 2026，上海科技大学）

**核心问题**：现有神经元解释方法有两个缺陷：(1) 依赖"激活幅值假设"——激活越大=概念越强，忽略负激活也可能正向影响预测；(2) 以输入为中心，只看高激活对应的输入图像，不反映神经元对输出的因果作用，在模型预测错误时尤其失效。

**方法**：
- 训练一个**线性**神经元编码器 En，把目标层残差流激活映射进冻结的 CLIP 嵌入空间。
- 损失 = 神经元-概念对比损失（与模型**预测标签**的文本嵌入对齐，输出端）+ 神经元-图像对比损失（与输入图像的 CLIP 图像嵌入对齐，输入端），均为对称 InfoNCE。
- 推理：单个神经元用 En(e_i)、SAE 特征用 En(W_dec f_i) 得到嵌入，与概念文本嵌入算余弦相似度，实现"概念→机制定位"与"机制→概念描述"。
- 附录 B.3 证明：因 En 线性，训练时的整体向量可分解为单元嵌入之和，所以对单个单元做推理不是分布外；余弦相似度使方法对激活尺度不敏感。
- 干预：对定位到的 top-5 单元做 ×2（增强）或 ×0（移除）。

**实验设置**：ResNet-50、ViT-B/16（ImageNet 分类）、CLIP ViT-B/16；10 万张 ImageNet 图训练 1 个 epoch；k-SAE 做特征解耦；DTD 纹理数据测未见概念泛化。

**主要结果**：
- 末层神经元描述：ImageNet-1k 类名集上准确率 100%（CLIP-Dissect 约 95–96%）；在 3k/10k/20k 常用词开放词表上 CLIP/Mpnet 分数显著优于 CLIP-Dissect。
- 干预：ResNet-50 神经元增强 +5.32%、移除 −17.24%；ViT-B/16 SAE 特征移除 −32.04%；基线常出现"增强反而降准确率"的矛盾。
- 消融：仅输出端对齐在 ImageNet 强但在 DTD 未见概念上失效；仅输入端泛化好但 ImageNet 弱；两者结合最稳。
- 逐层追踪真实/误判标签的相似度曲线，可定位"推理出错的层"。
- 附录 E.5：在 LLaVA-1.6-Mistral-7B 的**视觉塔**第 22 层做 SAE 特征干预，增强 +1.11%、移除 −1.87%（原始 1000 选 1 准确率仅 11.78%）；CLIP-Dissect 几乎无效果。
- 附录 E.4 用户研究：13 人、130 个回答，76.92% 偏好 MICLIP。
- 计算成本：训练 30 分钟、16GB 显存。

**优点**：
1. 同时考虑输入与输出，比纯输入相关性更接近因果作用，消融清楚证明了两者互补。
2. 线性编码器 + 理论说明，方法简单、便宜、可复现。
3. 同一框架适用于神经元和 SAE 特征，并用增强/移除双向干预验证定位质量（比单向干预更有说服力）。

**局限**：
1. 原文承认：解释上限受 CLIP 语义空间覆盖范围和偏差限制。
2. 原文承认：只在判别式视觉模型上验证；对 LLaVA 只干预了视觉塔，没触及语言模型部分，且任务是 1000 选 1 分类（基线准确率 11.78%），不是开放生成。
3. 输出端对齐依赖"预测类别标签"，天然只适合分类；对生成式模型的逐 token 输出没有直接定义。
4. 仍是事后方法：En 是外挂的线性探针，解释的忠实度靠干预间接验证，没有保证。
5. 用户研究规模小（13 人）。
6. 干预幅度在 ViT/CLIP 神经元上很小（多数 < 1.5%），说明单神经元层面的因果定位仍很弱，SAE 特征层面才明显。

**未来工作**：
- 原文：扩展到生成式模型；引入减轻 CLIP 偏差的方法。
- 推断：定义生成式模型逐 token 的"输出端语义"；在 MLLM 的语言模型部分做对齐和干预。

**与本项目的关系**：
- "输入+输出双端对齐"的思想可以直接借鉴到我们的概念对齐损失：视觉 token 的概念激活既要与图像内容（输入端）一致，也要与模型最终生成的词（输出端）一致。
- 它在 LLaVA 上只能动视觉塔、效果很小，恰好说明"事后在生成式 MLLM 里定位概念"很难——这是内生方案的动机之一。
- 增强/移除双向干预 + "矛盾结果标红"的评测范式，可以直接用于我们的概念 steering 评测。

## [1] Implicit Multimodal Alignment (IMA)（NeurIPS 2024，Sorbonne / Valeo.ai，Shukor & Cord）

**核心问题**：为什么冻结的 LLM 只训练一个小映射模块就能处理图像、视频、音频？三种假设：(1) 感知 token 被翻译成文本 token；(2a) 由模态专属子网络处理；(2b) 由同一套权重处理、靠别的原因泛化。

**方法（纯分析）**：
- 两种设置：单任务 ST（每个数据集训一个轻量 transformer 映射模块，10 个可学习 query、5 层；编码器用未与文本对齐的 ViT/TimeSformer/AST，也测了 CLIP、MAE）；多任务 MT（LLaVA-1.5 的 4 个变体，主要分析冻结 LLM、无预训练、transformer 映射的 LLaVA-1.5-4）。LLM 主要是 Vicuna-v1.5-7B，也测 OPT-6.7B、Llama 2-7B。
- 分析工具：跨层余弦相似度（主要用 token 平均后的 SimAvg，附录比较了 Max/Min/Avg/Med 五种）、token 范数、logit lens 解码出的词表分布（KL、熵）、Wanda 剪枝掩码的 IoU（衡量两种输入激活的权重是否相同）。

**主要发现**：
1. 感知 token 与文本 token 在 LLM 残差流中处于**不同的窄锥**，t-SNE 始终分开；不同感知模态之间也各自成锥；感知 token 范数更大、跨层变化更小；词表分布与文本不同且越往后差距越大。→ 不存在"完全翻译成文本"。
2. 两者激活的权重高度重叠（如 GQA vs Audiocaps 掩码 IoU 0.67）；剪枝掩码可跨任务、跨模态互换，性能只小幅下降。附录：同模态内 IoU 约 0.95（感知）/0.87（文本），跨模态约 0.6；稀疏度越高越能提出模态专属权重。
3. **隐式多模态对齐（IMA）**：训练映射模块的过程中、推理时逐层（中间层最高）两者的相似度都上升；在块内部（残差流之外）对齐比残差流中强得多（Vicuna 块内约 0.45 vs 残差流约 0.1），自注意力之后最高。
4. 解释：LLM = 残差流 + "转向块"。输入差异大，所以残差流中始终不同；各块只对残差流做小幅修正，并把两个窄锥往一起拉。作者据此主张泛化主要来自架构。

**应用含义**：
- IMA 分数与多个基准的任务性能正相关，可作模型选择代理指标。
- IMA 分数与幻觉（POPE、COCO）负相关 → 作者认为幻觉主因是内部感知/文本表示对齐不足。
- 视觉 token 变化小 → 在 FFN 中跳过部分视觉 token 计算，性能小降、算力大省。
- α-SubNet：取多模态剪枝掩码的交集得到一个约 47% 稀疏的通用子网络；平均分为基线的 68%，明显好于随机掩码（0%），但不如任务专属 Wanda（89%），在 Audiocaps、Clotho 上掉得很厉害（68→23、36→9）。

**优点**：
1. 模态覆盖广（图、视频、音频、文本），多个 LLM 和两种训练设置，结论经多种相似度度量交叉验证。
2. 把表示分析和实际收益（性能代理、幻觉解释、推理加速、压缩）连起来。
3. 块内 vs 残差流的对比很有洞察，提出了清晰的"转向块"解释框架。

**局限**：
1. 原文承认：只研究 ≤7B 的开源冻结 LLM，且只针对"感知 token 拼接到输入"的架构（不含 Flamingo 式交叉注意力），能否推广到更大/闭源模型未知。
2. 相关性 ≠ 因果：IMA 与幻觉、性能的关系只是相关，没有通过干预（提高对齐→减少幻觉）来验证；"幻觉主因是对齐不足"的结论偏强。
3. 主分析用 token 平均（SimAvg）；附录自己发现 MinSim、AvgSim 看不到同样趋势、MedSim 下窄锥效应减弱——说明结论由部分 token 驱动，单 token 层面并不都成立。
4. "架构是泛化主因"的论证主要是解释性的，没有对照架构实验（例如去掉残差或 LayerNorm）。
5. α-SubNet 在音频任务上性能损失很大，"一个子网络适用所有模态"的说法有保留。
6. 不涉及概念层面的解释：知道"对齐了"，不知道"对齐到了什么语义"。

**未来工作**：
- 原文（附录 B）：扩展到其他架构和更大模型；研究视觉 token 中编码了什么信息、LLM 如何从中提取信息；安全问题（拒答、组合性、指令遵循）；设计**在进入 LLM 之前就显式对齐多模态 token 的映射模块**。
- 推断：用干预实验验证 IMA 与幻觉的因果关系；把对齐分析做到概念级。

**与本项目的关系**：
- 直接相关的风险证据：视觉 token 在残差流里"天然不是文本"，如果我们期望视觉信息走 Steerling 的文本概念通道，就是在对抗这个现象；但 IMA 也显示块内（尤其 SA 后）对齐度高、且训练映射模块会自发提高对齐——说明这件事可训练、有抓手。
- 作者在未来工作里提出"显式对齐映射模块"，这正好是我们概念对齐损失的定位；可以直接引用作为动机。
- IMA 分数可作为我们的一个诊断指标（视觉 token 与概念嵌入/文本 token 的对齐度 vs 概念占比 vs 幻觉）。
- 注意：Steerling 的概念头在最后一层作用于 hidden state，而 IMA 显示残差流中两种 token 到最后仍分离——这正是"视觉信息可能漏进残差 ε"的机制原因，需要在方法中正面处理。

## [2] A Concept-Based Explainability Framework for Large Multimodal Models（CoX-LMM，NeurIPS 2024，Sorbonne，Parekh et al.，与 IMA 同组）

**核心问题**：LMM 内部表示缺乏概念级理解；已有 CAV/字典学习方法只用于 CNN 分类，没有针对"视觉编码器 + LLM"的多模态模型。

**方法（事后）**：
- 针对**单个目标词**（如 "dog"）：选出 GT 描述和模型预测描述里都含该词的图像，取该词在描述中**首次被预测的位置**、LLM 第 L 层（主实验 L=31，即 unembedding 前最后一层）的残差流表示，堆成矩阵 Z（维度 4096 × 样本数）。
- 用 **Semi-NMF**（字典可正可负、激活非负 + L1 稀疏）分解 Z≈UV，K=20 个概念（依据重建误差下降 50% 选定）。
- 多模态落地：视觉端取最大激活的 5 张图；文本端用 unembedding 矩阵对概念向量做 logit lens，取 top-15 词后过滤。
- 测试时把新样本投影到字典上，取激活最大的概念作局部解释。

**实验设置**：DePALM（冻结 CLIP ViT-L/14 + 10 个视觉 token + 冻结 OPT-6.7B，COCO 描述）；附录加 LLaVA-1.5（Vicuna-7B，576 个视觉 token），以及 ImageNet-ViT、MAE 编码器的 DePALM。目标词 8 个 + 附录 30 个额外 COCO 名词 + 多 token 词。

**主要结果**：
- 测试样本 top-1 概念的 CLIPScore/BERTScore 明显高于随机词、噪声图基线（如 Dog：0.610 vs 随机 0.519，GT 描述上限 0.783），但与 "Simple" 基线（直接取范数最大的表示）和 K-Means 差异经常**不显著**（附录 Tab.11 多处 p>0.1）。
- 概念重叠度：Semi-NMF 0.09–0.18，K-Means/Simple 常超 40%，PCA 近 0 但文本落地与图像不贴合 → Semi-NMF 是"有意义 + 多样"的最佳折中。
- 逐层：前 20 层的多模态落地不比随机词好，约 20–25 层开始出现多模态结构。
- 附录 B 多义性：手工标注 160 张狗图，"热狗"概念特异度 100%，"黑狗"93.3%，"斗牛犬"仅 50%（还对玩具狗激活）。
- 附录 G：只对视觉 token（因果注意力下看不到任何文本）做分解，深层同样出现多模态概念，且多个与文本 token 的概念相似。
- LLaVA 上：576 个视觉 token 保留 patch 位置，概念向量与各视觉 token 做内积即可得到廉价显著图。

**优点**：
1. 首个针对大规模 LMM 的概念字典方法，概念同时在图像和文字两侧可读，比 CNN 时代只有图像原型的 CAV 更易理解。
2. Semi-NMF 适配了有正有负的 LLM 表示，并系统比较了 PCA/K-Means/Semi-NMF 的取舍。
3. 评测较完整：局部解释、概念重叠、落地质量、逐层分析、多义性、多编码器与 LLaVA 验证，附统计检验。
4. 计算成本低（单卡，单个词十几分钟）。

**局限**：
1. 原文承认：字典按词单独学，概念不能跨词共享；主要只研究图像描述模型；落地方法最简单（最大激活样本 + logit lens）；CLIPScore/BERTScore 本身不完美。
2. 原文也明确说：目标是理解内部表示，**不解释模型输出**——没有衡量概念对预测的因果贡献，也没有干预实验。
3. 与 Simple/K-Means 基线常无显著差异，方法优势主要体现在"多样性"而不是"解释准确性"。
4. 只取最后一层、词首次出现的位置，覆盖面窄；K=20 固定。
5. BERTScore 评估要借助 LLaMA-3-8B 把词拼成句子，引入额外模型的偏差。
6. 概念是无监督得到、需要人工命名；样本量小（每个词几百到几千张图）。

**未来工作**：
- 原文：学习跨词共享的概念字典；推广到其他类型的 LMM；改进视觉定位和文本落地（如 tuned lens）；研究更好的可解释性评测指标。
- 推断：结合概念重要性估计与因果干预，把"表示解释"升级为"输出解释"。

**与本项目的关系**：
- 附录 G 是对我们有利的证据：LLM 深层的**视觉 token 自身**就带有可用文本词落地的概念结构，且与文本 token 的概念相似 → 支持"文本概念空间可以承载视觉信息"。
- 但它也显示这种结构只在深层（20 层以后）出现；Steerling 的概念头恰好在最后一层，这一点是对齐的。
- 我们的内生模型可以直接回答它回避的问题（概念对输出的因果贡献），并用 33K 个**共享、已命名**的概念代替逐词无监督字典——这正是原文列出的第一条未来工作。
- 其"概念向量 × 视觉 token 内积得到显著图"的做法可以直接用于我们的视觉定位评测。

## [3] Same Task, Different Circuits: Disentangling Modality-Specific Mechanisms in VLMs（NeurIPS 2025，Technion / UC Berkeley，Nikankin, Arad, Gandelsman, Belinkov）

**核心问题**：同一任务，VLM 在图像版本上的准确率普遍低于文本版本（如数图中物体 vs 数文本中的词）。差距从哪里来？

**方法**：
- 构造 5 个"图像/文本成对"的任务：物体计数、两位数算术（写在白底图上）、CLEVR 空间顺序、事实回忆（人物/地标图 vs 名字）、情感分析（生成图 vs 描述）。所有提示对齐到位置模板，答案限单 token。
- 电路发现：用带积分梯度的归因修补（AP-IG，k=5）给每个组件（注意力头、单个 MLP 神经元，按位置区分）打分；取达到 80% 忠实度的最小电路。
- 把电路按位置切成三段：数据（图像或文本内容）、查询（问题）、生成（最后一个 token）。
- 结构比较：跨模态电路的 IoU，并用同大小随机电路归一化。功能比较：把某一段子电路换成另一模态的对应段，看忠实度是否保持。
- 改进方法 **back-patching**：先前向一次记录视觉 token 在后层（l_src 附近 1/3/5 层窗口）的表示，再前向一次把它们贴回前层（l_dst）。

**实验设置**：Qwen2-VL-7B、Pixtral-12B、Gemma-3-12B；附录加 PaliGemma2 3B/10B/28B、VQAv2（3000 条）、RealWorldQA（765 条）。8×L40，约 200–300 GPU 小时。

**主要结果**：
- 结构：数据位置子电路跨模态几乎零重叠；查询位置仅约 12%；生成位置约 38%。视觉任务电路平均用 15% 组件，文本任务 7%。
- 功能：查询、生成子电路**可互换**（结构不同但功能等价）；数据子电路互换后忠实度降到随机水平 → 差距主要来自"数据 token 如何被处理"。
- 视觉 token 与对应文本 token 的最大余弦相似度随层数上升，但**要到较深层才高**——此时信息已经从数据位置流走了，"对齐得太晚"。
- back-patching 平均提升 4.6 个百分点，约补上 32% 的模态差距；PaliGemma2-10B 上算术提升 28%。对照实验：同样操作施加在文本提示上，约 79% 的情况下收益更小 → 收益主要来自"提前拿到文本对齐的表示"，不只是多算了几层。
- 通用 VQA：VQAv2 +3–4.6 点，RealWorldQA +0.9–2.8 点。
- 迭代 back-patching 超过一次后性能下降（表示变得越来越分布外）。

**优点**：
1. 任务设计巧妙：成对的图文任务把"模态"单独隔离出来，是少见的干净对照。
2. 结构（IoU）+ 功能（子电路互换）双重分析，得出"不同零件、相同功能，差异集中在数据位置"的清晰结论。
3. 从机制分析直接导出免训练的改进方法，且有对照实验排除"只是多算"的解释；覆盖多个模型和规模。
4. 代码、数据、TransformerLens 的 VLM 补丁都开源。

**局限**：
1. 原文承认：只做单图、图在问题前、单 token 答案的简单任务（因为电路方法只支持单 token 输出）；只研究 adapter 式 VLM；剩下约 68% 的差距原因不明。
2. back-patching 的最佳 (l_src, l_dst, 窗口) 是**逐模型逐任务搜索**的，而且看起来是在评测数据上选的——实际部署时没有这个先验，提升可能被高估；通用 VQA 上也做了设置搜索。
3. 需要两次前向，推理成本翻倍。
4. 结论并非所有情况都成立：Pixtral 在计数、颜色排序上图像反而比文本好（66.1% vs 49.3%、80.6% vs 77.4%），算术文本只有 25.7%；事实回忆上对照实验常常胜过 back-patching。
5. 数据位置无法一一对应，只能丢掉位置信息比较，结构重叠的度量较粗。
6. 解释停留在"表示相似度"层面，没有说明对齐到了什么语义。

**未来工作**：
- 原文：多图、不同提示顺序、更依赖视觉的推理任务；其他融合架构；解释剩余的模态差距；按 token 分配不同计算量（视觉 token 可能需要更多层）。
- 推断：把"让视觉 token 更早对齐文本"变成训练目标，而不是推理时修补。

**与本项目的关系**：
- 核心证据："视觉 token 对齐文本太晚"是模态差距的主因之一。如果我们的概念头只在最后一层，视觉信息即使最终对齐了，也可能来不及在前面层通过文本概念被使用。→ 方法设计上应考虑**让视觉 token 更早进入概念/文本对齐空间**（例如在投影层或早层就施加概念对齐损失），这正是他们推理时 back-patching 的训练版。
- "查询与生成子电路跨模态功能等价"支持我们的设定：只要视觉数据被映射到文本概念空间，下游的语言处理可以复用。
- 其成对图文任务数据集可以直接拿来做我们的评测：同一任务图像版和文本版的概念激活是否一致，是"视觉走了文本概念通道"的直接检验。

## [4] HEIE: MLLM-Based Hierarchical Explainable AIGC Image Implausibility Evaluator（CVPR 2025，清华 / OPPO / 北大）

**核心问题**：AI 生成图像常有手指扭曲、五官错位等瑕疵。专用小模型（如 RAHF）能画瑕疵热力图但不会解释、缺常识、泛化差；通用 MLLM 懂常识但定位不了细小瑕疵，也不能输出像素级热力图。

**方法**：以 InternVL-8B 为底座微调。
- **CoT 驱动的"三位一体"评估器**：让 LLM 按 5 步输出——图像描述 → 问题区域识别 → 特殊 [MAP] token → 逐区域问题分析 → 特殊 [SCORE] token。
- **自适应分层瑕疵映射器**：取 [MAP] token 最后一层隐状态，与视觉编码器特征做两次双向交叉注意力，输出热力图；按分辨率把图切成 N 块，每块一个局部 [MAP] token 出局部热力图，外加一个全局 token 出全局热力图；两者建模为拉普拉斯分布，用学到的不确定性 e^(−σ) 加权融合；用 focal loss 处理不平衡。
- **可信度打分器**：[SCORE] token 经 FFN 回归一个分数，热力图经卷积+FFN 得另一个分数，再校准融合。
- **Expl-AIGI-Eval 数据集**：在 RichHF-18K 和 AbHuman 的瑕疵掩码上画红圈（视觉提示），让 Claude-3.5-Sonnet 自由写分析，再用 GPT-4o + 上下文示例整理成固定格式。

**实验设置**：RichHF-18K、AbHuman；4×A100-80G；热力图用 MSE/KLD/CC/SIM/AUC-Judd，分数用 PLCC/SRCC，解释用困惑度、GPT-4o 评分、人工评分；两数据集互为零样本迁移。

**主要结果**：
- RichHF-18K：MSE 0.00825、CC 0.574、PLCC 0.697，均略优于 RAHF 增强提示版（0.00920 / 0.556 / 0.693）——提升幅度不大，且 RAHF 未开源只能引用其论文数字。
- AbHuman：CC 0.684、AUC-Judd 0.938，大幅优于 CLIP/EVA-CLIP/InternViT 基线。
- 解释质量：GPT-4o 评分 4.58、人工评分 4.35，高于 GPT-4o 本身（3.83/4.00）和 Claude-3.5（3.94/4.08）。
- 消融：全局+局部+不确定性融合最好；分数用 [SCORE]+热力图校准最好（PLCC 0.697），直接让 LLM 输出数字只有 0.216；CoT 文本带来小幅提升（CC 0.553→0.574），用 GT CoT 再到 0.580。

**优点**：
1. 把定位（热力图）、量化（分数）、文字解释统一到一个 MLLM 里，任务定义对应用友好。
2. 分层 + 不确定性融合的设计合理，消融完整。
3. 发布了带解释标注的数据集；跨数据集零样本实验说明借助 MLLM 常识有泛化收益。

**局限**：
1. **这里的"可解释"是输出层的文字说明，不是模型机制的解释**：文字解释是模型生成的，没有任何机制保证它与热力图、分数的实际计算一致（CoT 忠实度问题）。
2. 解释标注来自 Claude-3.5 + GPT-4o，模型学的是模仿商业模型的说法；且在 GT 掩码上画红圈让 Claude 写解释，等于把"答案"告诉了标注模型。
3. 用 GPT-4o 评估"与 GT 解释的相似度"，而 GT 解释本身部分由 GPT-4o 整理 → 评估有自我偏好风险；人工评估细节（人数、协议）正文未说明。
4. 相对 RAHF 的提升很小，且对比数字无法复现。
5. CoT 对热力图、分数的帮助有限（CC +0.02），"三者相互增强"的说法偏强。
6. 附录只有环境与可视化，缺少失败案例分析。

**未来工作**：
- 原文：提升 MLLM 框架的推理效率和性能。
- 推断：检验文字解释与热力图的一致性；把方法推广到视频生成质量评估。

**与本项目的关系**：相关度低，但有两点可用。
1. 可作为"输出层解释 ≠ 机制解释"的典型例子写进相关工作：这类方法的解释由模型生成、不受约束，而内生可解释模型的解释由计算结构保证。
2. 若以后做医学场景（如抑郁评估），"特殊 token 回归分数 + 与文字解释联合训练"的结构可以借鉴；我们可以让分数 token 必须经过概念瓶颈，解决它的忠实度缺口。

## [5] Interpreting Object-level Foundation Models via Visual Precision Search（VPS，CVPR 2025 Highlight，中科院信工所等，Chen et al.）

**核心问题**：Grounding DINO、Florence-2 这类图文融合的检测/定位基础模型难以解释：梯度法（Grad-CAM、ODAM）因图文特征融合而定位不准；扰动法（D-RISE）的显著图噪声大。

**方法（黑盒、输入级归因）**：
- 用 SLICO 超像素把图像切成 m 个子区域（默认 100 个），把"找关键区域"建模为子集选择问题。
- 集合函数 F = 线索分（只保留子集 S 时，与目标框 IoU × 类别置信度的最大值）+ 协作分（去掉 S 后，1 − 同样的最大值）。
- 在次模性（边际收益递减、单调非负）下贪心搜索可达 (1−1/e) 近似；按贪心顺序的边际增益给每个区域打分得到显著图。
- 附录 A 给出次模性证明：依赖泰勒一阶近似，并**假设所选区域是"有效的"（梯度为正）**、忽略部分小项。原文也说明：对不输出置信度的 MLLM 式检测器（如 Florence-2），理论保证不完全成立。
- 复杂度：贪心需要约 |V|²/2 次前向推理（100 个区域约 5000 次）。

**实验设置**：MS COCO（检测，每类抽 5 正确/3 误分类/3 漏检）、LVIS V1 稀有类（零样本检测）、RefCOCO（指代表达，500 正确 + 200 错误）；模型 Grounding DINO、Florence-2（无置信度，只能用 IoU 引导）；附录加 Mask R-CNN、YOLOv3、FCOS、SSD。基线 Grad-CAM、SSGrad-CAM++、ODAM、D-RISE、D-HSIC。指标：Insertion/Deletion AUC（分总分、类别、IoU 三种）、平均最高分、Point Game、Energy PG；失败样本用"解释成功率 ESR"。

**主要结果**：
- Grounding DINO 正确样本：Insertion 相对 D-RISE 提升 23.7%（COCO）、20.1%（RefCOCO）、31.6%（LVIS）；梯度法在融合模型上忠实度很低。
- Florence-2：Deletion 大幅提升（COCO 上 50.7%）。
- 失败解释：误分类 Insertion +54.7%（COCO）、ESR +19.5%；漏检 Insertion +36.7%、ESR +14.4%；可视化显示背景干扰、相似物体混淆等原因。
- 传统检测器上同样全面领先；消融显示线索分主要提升 Insertion、协作分主要提升 Deletion；子区域越多越忠实但耗时迅速增加。
- 附录 C：同一目标、不同指代文本（"blue guy" vs "right person"）得到不同显著图。

**优点**：
1. 黑盒、不依赖梯度，天然避开图文融合对梯度归因的干扰，可跨架构使用（融合式、MLLM 式、传统检测器）。
2. 有次模性理论框架和近似保证，方法设计与目标（少区域即可检出、去掉即失效）一致。
3. 不仅解释正确预测，还定量解释失败（误分类、漏检、定位错误），并提出 ESR 指标。
4. 实验覆盖广，附逐样本提升分布图。

**局限**：
1. 原文承认：超像素划分决定上限，正负贡献混在同一区域时会失真；区域多时计算量大（O(|V|²)）。
2. **评测存在循环性**：线索分就是 Insertion 曲线上度量的量，协作分对应 Deletion；方法本质上是在直接贪心优化评测指标，领先幅度会因此被放大。
3. 次模性证明依赖近似和"所选区域有效"的假设，不是严格保证；对 Florence-2 等 MLLM 检测器理论不成立。
4. 只到输入区域层面，**不解释模型内部机制**，也不给出语义概念（只知道"哪块区域重要"，不知道"因为什么特征"）。
5. 仅针对检测/定位类输出（框 + 置信度），无法直接用于开放式文本生成的 MLLM。

**未来工作**：
- 原文：改进划分策略；加速搜索或借助外部知识剪掉无关区域；对 transformer 内部参数做归因；扩展到实例分割；找出并修正有问题的参数以改进模型。
- 推断：扩展到生成式 VLM 的逐 token 归因；与概念级解释结合。

**与本项目的关系**：
- 属于"输入级事后归因"，与内生可解释模型不在同一层面，但可以作为我们的**外部对照**：我们的模型能给出"概念 + 视觉区域"的内生归因，可以用它的 Insertion/Deletion 协议检验我们的视觉定位是否忠实，并与 VPS 比较。
- 它对梯度法在图文融合模型上失效的观察，也支持"事后梯度解释在多模态模型中不可靠"的论点。
- 注意：用 Insertion/Deletion 评测时要警惕它的循环性问题，我们自己的评测也应避免"优化什么就评什么"。

## [6] Cross-modal Information Flow in Multimodal Large Language Models（CVPR 2025，阿姆斯特丹大学等，Zhang, Yadav, Han, Shutova）

**核心问题**：自回归 MLLM 在做 VQA 时，视觉信息和语言信息**在哪一层、以什么方式**融合，并最终送到答案位置？

**方法（机制分析）**：
- **注意力阻断（attention knockout）**：在注意力掩码里把"目标位置 → 源位置"的边设为 −∞，在以某层为中心的 k=9 层窗口内阻断，测量正确答案概率的相对变化。阻断三类边：最后位置 → 图像 / 问题 / 自身；问题 → 图像；问题 → 与问题相关物体所在的图像块 vs 其余图像块（用 GQA/Visual Genome 的包围框划分）。
- **logit lens**：逐层用 unembedding 解码最后位置，追踪答案词概率（区分首字母大小写）。
- 附录：模块阻断（把某层 MLP 或注意力输出置零）后，用问题位置最后一层 top-10 解码词的 Jaccard 相似度衡量语义变化。

**实验设置**：GQA 验证集中挑选 6 类题型（属性选择、类别选择、关系选择、属性比较、逻辑、属性查询），每类约 920 对、仅用模型答对的样本（各模型准确率 >95%）；模型为 LLaVA-1.5-7B/13B、LLaVA-v1.6-Vicuna-7B、Llama3-LLaVA-NeXT-8B（均用 CLIP ViT-L-336）。附录：窗口大小 k=1–15、最后子词、OKVQA/A-OKVQA、高范数图像块（注意力 sink）排除、与纯文本 LLM 的对比。

**主要结果**：
1. 最后位置自身几乎不含答案信息；**问题 → 最后位置**的信息流在中间层起决定作用（阻断后概率最多降约 30%）；**图像 → 最后位置几乎没有直接作用**。
2. 图像 → 问题的信息流发生**两次**：低层（约 0–4 层）先把整图的通用信息写入问题位置（阻断降约 60%，主要来自"其余图像块"），约第 10 层再把与问题相关物体区域的信息写入（降约 21%，来自"相关图像块"）。
3. 答案在中间层（多模态融合刚完成时）以小写形式出现，到高层再转为首字母大写 → "先语义、后句法"。
4. 附录：MLP 比注意力对构建多模态语义更关键；排除约 3.3 个高范数图像块后结论不变；把图像换成密集描述文本后，信息会从描述直接流向最后位置——与图像的行为不同；**在 LLaVA-v1.6-13B 上去掉最后 20 层的图像 token，准确率不变、推理时间约减 40%**。
5. 四个模型结论一致；13B 比 7B 的第一阶段整图信息流更强。

**优点**：
1. 问题清晰、方法干净：注意力阻断是直接的因果干预，且在四个模型、多种题型、多种窗口大小下稳健。
2. 用物体包围框把"整图 vs 相关区域"区分开，得出"先整体、后局部"的两阶段融合图景，比单纯看注意力权重更有说服力。
3. 附带实用结论（高层可丢弃图像 token 加速）；附录对照纯文本 LLM 很有启发。

**局限**：
1. 只分析 LLaVA 系列（同一视觉编码器、同一"图在前、问题在后"的格式），结论对其他架构、其他输入顺序未必成立。
2. 只用简单的单词/短语答案、且只用模型答对的样本；未分析错误样本的信息流，也不涉及长文本生成。
3. 大窗口（k=9）阻断会同时影响多层，定位粒度粗；附录显示窗口增大时两阶段会合并。
4. 只回答"信息在哪、何时流动"，不回答"流动的是什么语义"；也没有给出改进模型的方法（加速实验除外）。
5. 相对概率变化是单一指标，未报告绝对准确率变化和统计显著性。

**未来工作**：
- 原文（结论部分较简略）：为理解 MLLM 中两种模态的交互提供新研究方向，并最终改进模型；附录提出高层移除图像 token 的加速思路。
- 推断：扩展到其他架构（交叉注意力式、原生多模态）、多图、长文本生成、错误样本分析；结合概念级解释说明每个阶段传递的内容。

**与本项目的关系**：
- 关键启示：在 LLaVA 式模型里，**视觉信息基本不直接流向答案位置**，而是先写入问题 token，再由问题 token 送到最后位置。对我们意味着：如果只看视觉 token 位置上的概念激活，可能错过真正起作用的"被视觉信息改写后的文本 token"的概念；评测"视觉走没走概念通道"时，应同时看视觉 token 和问题/答案 token 的概念分解。
- "高层可以丢弃图像 token"与 IMA、Same Task 的发现一致：视觉信息的作用集中在低中层。而 Steerling 的概念头在最后一层——这是一个需要正视的结构性张力：最后一层的概念分解能否反映低中层就已完成的视觉融合？可能需要把概念监督或读出扩展到中间层。
- Steerling 是块内双向注意力，信息流模式可能与自回归 LLaVA 不同，这本身就是一个可以用他们的注意力阻断方法做的对比实验。

## [7] Measuring Cross-Modal Interactions in Multimodal Models（InterSHAP，AAAI 2025，剑桥大学，Wenderoth et al.）

**核心问题**：医疗多模态模型需要可解释，但现有跨模态交互度量（PID、EMAP、SHAPE）要么只支持两个模态，要么只能给整个数据集一个数、不能给单个病人，要么需要标签或依赖模型性能。

**方法（黑盒、模态级）**：
- 把每个**模态**当作合作博弈中的一个玩家，用 **Shapley 交互指数（SII）** 计算两两模态的交互值 φ_ij；模态自身贡献 φ_ii = Shapley 值 − 该模态所有交互值之和。
- 全局：对每个 φ_ij 先在样本上取平均再取绝对值得到 Φ_ij；InterSHAP = 交互项之和 / 全部项之和，即"模型行为中由跨模态交互解释的比例"；模态贡献 = 1 − InterSHAP。
- 局部：对单个样本逐项取绝对值后计算同样的比例。
- 遮蔽方式：把某模态替换成训练集中随机另一个样本的该模态，重复 n 次取平均；目标输出取最高类概率（所以不依赖标签、不依赖性能）。
- 复杂度：随模态数指数增长（要算全部联盟），与每个模态的特征数无关。已集成进 SHAP 可视化包。

**实验设置**：
- 合成数据：HD-XOR（两个比特的 XOR 投影到约 100 维，分"独有/协同/冗余/随机"四种设置，2–4 个模态，各 2 万样本）；附录另用 PID 论文的 SUM 数据集。模型为三层全连接网络，比较早/中/晚融合。
- 真实医疗数据：多模态单细胞（RNA 4000 基因 + 140 蛋白，4 类细胞，7132 个细胞，类别极不平衡）；MIMIC-III（24 小时时序 + 静态信息，ICD-9 分类和死亡率预测，MultiBench 的基线与 MVAE 模型）。

**主要结果**：
- 用 XOR 函数本身验证：独有设置 0%、协同设置 99.7%，符合预期；全连接网络为 0.2% / 98.0%。随机数据集上模型只有随机性能，但 InterSHAP 仍测到约 60% 的交互 → 体现"与性能无关"。
- 局部版本在独有设置高估（1.8%）、协同设置低估（96.9%），作者归因于遮蔽误差。
- 3、4 个模态时，协同设置的 InterSHAP 从 98% 降到 64%，作者无法确定是数据集协同度下降、模型没学好（F1 从 94.4 降到 76.4），还是方法本身的问题。
- 单细胞：交互只占 0.4–1.9%，但小类别（B 细胞、单核细胞前体）的预测主要依赖交互；早融合交互 > 晚融合。
- MIMIC-III：ICD-9 任务交互 1.2–6.8%，死亡率任务约 11–12%；MVAE 交互多于基线；EMAP 基本测不到交互。

**优点**：
1. 定义清楚、结果直观（一个百分比），同时给全局和单样本解释，支持两个以上模态，不需要标签。
2. 在"真值已知"的合成数据上做了验证，并与 PID/EMAP/SHAPE 系统比较；代码开源并接入 SHAP 生态。
3. 面向医疗场景，指出了"小类别依赖跨模态交互"这类对模型调试有用的发现。

**局限**：
1. 原文承认：运行时间随模态数指数增长；3 个以上模态的协同情形没能被清楚验证；SII 只捕捉两两交互，高阶交互可能漏掉。
2. **粒度只到模态级**："文本和音频有多少交互"，但不知道是什么内容/概念在交互，对临床医生的可操作性有限。
3. 全局版本对 φ_ij 先平均再取绝对值，正负效应相互抵消会低估交互；局部版本与全局版本不一致。
4. 遮蔽方式（替换为另一样本的模态）会产生分布外组合，交互值受遮蔽方式影响（作者也把 SHAPE 的偏差归因于遮蔽）。
5. "与性能无关"是双刃剑：随机数据上也测出 60% 交互，说明它衡量的是模型行为而非有用的交互，解读需谨慎。
6. 验证只用了小型全连接网络和经典多模态模型，未涉及大模型。

**未来工作**：
- 原文：研究 SII 的近似方法以降低计算量；尝试其他交互度量（Faith-SHAP、Shapley-Taylor 交互指数）；用特征级指标处理 3 个以上模态。
- 推断：把交互分析从模态级细化到概念级；应用到多模态大模型。

**与本项目的关系**：
- 这是我们列表中唯一以医疗为动机、且直接处理 >2 模态的工作，对后续**抑郁症场景（文本 + 音频 + 面部）**直接相关：可以作为模态级基线，我们的模型如果能给出"哪个模态的哪个概念"的贡献，就是在它的模态级粒度之上更进一步。
- 其 XOR 式"独有/协同/冗余"合成数据的设计，可以借鉴来验证我们的模型能否正确区分单模态概念和跨模态概念。
- 它的真实数据结果（交互只占很小比例）提示：多模态模型可能大多只依赖单一模态——在抑郁数据上也需要检查我们的模型是否真正利用了音频/面部。

## [8] SAE-V: Interpreting Multimodal Models for Enhanced Alignment（ICML 2025，北京大学，Lou, Li, Ji, Yang）

**核心问题**：SAE 已成为解释 LLM 的主流工具，但扩展到 MLLM 时面临模态融合、跨模态表示难分离的问题；而且自下而上的可解释方法缺少"重建损失之外"的有效评价方式。能否让可解释性直接服务于对齐？

**方法**：
- **SAE-V**：结构与标准 SAE 相同（ReLU 编码 + 字典解码，L1 稀疏），区别在于**用多模态数据（Obelics 图文交错）在 MLLM 上训练**，而不是用纯文本（The Pile）。LLaVA-NeXT 第 16 层、65536 个特征；Chameleon 第 8 层、131072 个特征；8×A800 每次约 21 小时。
- **跨模态权重**：对每个特征，取激活最高的 top-K 文本 token 和 top-K 视觉 token，计算两组隐状态的余弦相似度，作为该特征"融合多模态信息的能力"。
- **数据过滤**：一条数据的分数 = 它激活的所有特征的跨模态权重之和，按分数排序保留高分数据；对照算法为 L0 排序、共现 L0 排序（同时在文本和视觉 token 上激活的特征数）。
- 用 ImageNet 图像块过滤（按 SAE-V 特征保留 75/50/25% 的块）检验特征是否抓住关键视觉信息。

**实验设置**：LLaVA-NeXT-7B/13B（Mistral/Vicuna）、Chameleon-7B、Anole-7B、Mistral-7B；对齐实验用 Align-Anything 的 4 万条图文→文本偏好数据做 DPO，另用 RLAIF-V、MMInstruct；在 LLaVA-Bench 上评测；与 IFD 指标比较。

**主要结果**：
- 重建：SAE-V 的重建损失明显低于纯文本 SAE；在 Chameleon/Anole 上文本 SAE 甚至不如全零基线；SAE-V 可迁移回原 LLM。
- 可解释特征示例：跨图文都对"杜宾犬"激活的特征、对"对称"这一抽象概念激活的特征（定性展示）。
- ImageNet：只保留 25% 图像块时，L0/L1/余弦分数法仍保持约 70% 准确率，明显高于随机保留。
- 数据过滤：LLaVA-NeXT-7B 上用 20% 数据达到全量的 108%，共现过滤在 50% 数据时达到 115%；Chameleon + RLAIF-V 用 10% 数据达到 125%；与 IFD 峰值相近（略低），但无需额外训练模型。
- 模型平均余弦分数与性能的相关系数 0.84。
- 附录：只训练约 3 万个特征真正被激活（字典大量冗余）；对 A-OKVQA 分别掩码文本和图像，图像信息冗余度高于文本。

**优点**：
1. 首次系统地把 SAE 扩展到多种架构的 MLLM（CLIP 式和早融合式），并证明"用多模态数据训练 SAE"是必要的。
2. 把可解释性转化为有实际收益的工具（数据过滤），为"如何评价 SAE"提供了下游指标。
3. 过滤方法无需额外模型，自洽且计算简单；多模型、多数据集、小子集调参等消融较完整；代码和模型开源。

**局限**：
1. 原文承认：跨模态相似度、共现特征与模型性能之间的理论关系不清楚；只研究了图文，音频、视频、具身场景未涉及。
2. **可解释性本身几乎没被定量评估**：特征语义只给了少数定性例子，没有自动解释评分、没有干预/steering 实验来验证特征的因果作用。
3. 只在单层训练 SAE；约一半特征从不激活（死特征），SAE 训练代价大。
4. 数据过滤收益在 LLaVA-Bench 这一个小基准上测得，存在评测噪声；最优保留比例需要搜索，不同数据集差异很大（10%–70%）。
5. "跨模态权重"用 top-K 文本与视觉 token 隐状态的余弦相似度定义，但 IMA 等工作表明两种 token 本身分布在不同的窄锥中，这个度量是否衡量了语义对齐而非几何位置，未讨论。
6. 相关系数 0.84 的拟合样本是同一批实验的模型，存在自证风险。

**未来工作**：
- 原文：建立 SAE-V 的理论基础；扩展到音频、视频、具身智能等更多模态。
- 推断：用 SAE-V 特征做干预/steering；多层 SAE；把"跨模态特征"用于训练时的正则化而不只是数据过滤。

**与本项目的关系**：
- 它说明：用**文本训练的字典解释多模态模型会失败**（重建差、甚至不如零），必须用多模态数据训练。这对我们是一个直接警告——Steerling 的 33K 概念和 10 万发现概念都是在纯文本上学的，接入视觉后可能出现同样的"字典不覆盖视觉"问题，即视觉信息大量进入残差 ε。这应作为我们诊断实验的核心检查项，并在方法中考虑为视觉扩充/微调发现概念头。
- "共现特征"（同时被文本和视觉 token 激活的特征）的定义可以直接用来衡量我们的概念空间是否真正多模态化。
- 数据过滤思路可作为我们模型的一个下游应用：用内生概念的跨模态一致性筛选训练数据。

## [9] Universal Sparse Autoencoders: Interpretable Cross-Model Concept Alignment（USAE，ICML 2025，York University / Vector / Harvard Kempner 等，Thasarathan, Forsyth, Fel, Kowal, Derpanis）

**核心问题**：已有的概念可解释性方法一次只分析一个模型；寻找"多个模型共有的概念"的方法（Rosetta Neurons 等）是事后逐模型提取再匹配，计算代价大、不能在模型之间转换。能否直接学一个跨模型的共享概念空间？

**方法**：
- 每个模型 i 有自己的编码器 Ψ^(i) 和解码器 D^(i)，但**共享同一个稀疏编码空间 Z**（TopK SAE，字典 6144 = 8×768）。
- 训练时每步随机选一个模型 i，把它的激活编码成 Z，再用**所有**模型的解码器分别重建各自的激活，损失求和，只更新被选中的编码器/解码器对（兼顾显存和收敛速度）。附录：L2 损失改为 L1，编码器加 BatchNorm，各模型激活先标准化，统一 patch 数。
- 评价指标：跨模型重建 R²（i 编码 → j 解码）；**点火熵**（一个概念在各模型上激活频率的归一化熵，1 表示均匀共享）；**共点火比例**（同一输入上所有模型同时激活的比例）；概念能量（对重建的贡献）；与单模型独立 SAE 的字典余弦相似度。
- 应用：**协同激活最大化**——对同一个概念维度，在每个模型上分别优化输入图像，直观比较不同模型如何编码同一概念。

**实验设置**：DinoV2、SigLIP、监督 ViT 最后一层 patch 激活；ImageNet 训练；单张 RTX 6000 约 3 天；附录在 DTD、CelebA 上测分布外泛化。

**主要结果**：
- 发现从颜色、形状、纹理到物体部件、"群体中的动物脸"等组合概念的共享概念（定性）。
- 跨模型重建 R² 非对角项为正，说明确有共享特征；DinoV2 自重建最好。
- 点火熵呈双峰（约 1 和 0.6），多数概念是共享的；前约 100 个最重要概念有 50–80% 的时间共点火；共点火频率与概念能量相关（高频概念上 r=0.89）→ **越共享的概念越重要**。
- 与独立 SAE 相比：ViT 38%、DinoV2 26%、SigLIP 23% 的概念能在独立 SAE 中找到对应（余弦 >0.5），随机基线 AUC 0.13 → 通用训练既保留部分原有概念，也发现了独立训练中没有的共享概念。
- 找到模型独有概念：DinoV2 独有深度、透视、视角不变、三维几何类概念；SigLIP 独有"同时对物体和对应文字激活"的概念（如星形与 "star" 字样、乐器与乐谱）。
- 在 DTD、CelebA 上重建和共点火趋势保持一致。

**优点**：
1. 把"跨模型概念对齐"变成端到端训练，而不是事后匹配，思路简洁、可扩展；训练策略在效率和收敛之间做了合理折中。
2. 提出点火熵、共点火比例等衡量"概念普遍性"的指标，并发现普遍性与重要性强相关。
3. 能同时找共享概念和模型独有概念，对比较不同预训练目标很有用；协同激活最大化是新颖的可视化工具。
4. 算力需求低（单卡）。

**局限**：
1. 原文承认：模型数增加时对超参数敏感；只用最后一层；有一小部分概念无法解释（与普通 SAE 相同的问题）。
2. **只研究纯视觉模型**（SigLIP 也只用了图像塔），没有涉及语言模型或生成式多模态模型；"跨模态"只体现在 SigLIP 概念里偶然出现文字。
3. 可解释性评估以定性可视化为主，缺少自动解释评分或人工研究；没有因果干预实验证明概念对模型输出有作用。
4. 与独立 SAE 的重叠只有 23–38%，"通用空间是否忠实于各个模型"仍有疑问；共享空间可能迫使模型特有的信息被压缩或丢失。
5. 概念无名称，需要人工看图命名。

**未来工作**：
- 原文：探索不同层深度的通用特征；解决多模型时的超参数敏感问题；缓解叠加导致的不可解释概念。
- 推断：扩展到跨模态（视觉编码器 + 语言模型）的通用概念空间；引入因果干预验证。

**与本项目的关系**：
- 方法上最有借鉴价值的一点：**用"共享编码 + 各自解码"的方式强制不同来源的表示落到同一个概念空间**。我们的问题（让视觉 token 与文本 token 共用 Steerling 的概念空间）可以看成 USAE 的"跨模态、内生版"：不同的是我们的共享空间是现成的 33K 已命名概念，而且要在模型内部训练中实现，而不是事后外挂。
- 点火熵、共点火比例可以直接用来衡量我们的概念在"视觉输入 vs 文本输入"上是否被均衡使用。
- "普遍性越高的概念越重要"这一发现提示：跨模态共享的概念可能正是承载主要信息的概念，可作为我们的一个验证假设。

## [10] Token Activation Map to Visually Explain Multimodal LLMs（TAM，ICCV 2025 Oral，香港科技大学，Li et al.）

**核心问题**：传统视觉解释方法（CAM 系列、注意力、LRP）为"单一输出"设计；MLLM 逐个生成多个 token，**前文 token（提示词和已生成的答案词）会把自己的视觉激活"带进"后面 token 的解释里**，造成冗余激活（例如解释"叉子"时，热力图里还残留"盘子"的区域）。

**方法（事后，无需反向传播）**：
- 基础激活图：视觉 token 特征 × 输出分类层（lm_head）中该词的权重向量，取正值——本质上是在视觉 token 上做 CAM/logit lens。
- **估计因果推断（ECI）**：受潜在结果模型启发，把"没有该 token 时的结果"估计为前文 token 激活图的加权和（权重是前文 token 与当前 token 的文本相关度，相同词的相关度置 0），用最小二乘求缩放系数 s，从当前激活图中减去 s × 干扰图。
- **秩高斯滤波**：窗口内按数值排序后，用以中位数为中心的一维高斯核加权（方差用变异系数），去除 transformer 激活图中的椒盐噪声。
- 评测：提出 Obj-IoU（名词对应物体掩码的 IoU）、Func-IoU（功能词应尽量没有激活）和二者的 F1-IoU。**明确只评"合理性（plausibility）"而不评"忠实性（faithfulness）"**，理由是扰动输入会改变 MLLM 生成的文本，使忠实性测试失效，而且代价过高。

**实验设置**：Qwen2-VL-2B/7B、LLaVA-1.5-7B/13B、InternVL2.5-2B/4B/8B；COCO Caption（5K）、GranDf、OpenPSG 有掩码的数据集定量评测；QK-VQA、STAR 视频等定性评测；对比 CAM、Grad-CAM、Grad-CAM++、Layer-CAM、注意力、Rollout、CP-LRP、AttnLRP 等。

**主要结果**：
- Qwen2-VL-2B 上 F1-IoU 在 COCO Caption 提升 8.96%，OpenPSG 提升 8.54%；两个模块叠加的收益大于各自收益之和（3.7% + 1.33% → 8.96%）。
- 7 个 MLLM 上都有 5.45–11.0% 的提升；TAM 的 F1-IoU 为 30.7–41.5%，CAM 为 23.6–34.4%。
- 附录 F：随机配对 CAM 的 L1 距离与文本相关度的 Pearson 相关 −0.16（最相关词对 −0.36），用来证明"上下文干扰"确实存在；安慰剂检验（把目标 CAM 换成随机的更早 CAM）使 Obj-IoU 降到原来的约 1/4。
- 定性应用：属性（颜色、形状、动作、位置）解释、失败案例分析（模型能定位物体但与知识对不上）、视频、多轮对话、多图、模型间比较（Qwen2-VL 的激活图质量优于 LLaVA 和 InternVL）。
- 附录 K：模型越大，物体用越少的 token 编码，召回下降、精度上升。

**优点**：
1. 抓住了生成式 MLLM 与传统单输出模型在解释上的本质差别（token 间干扰），问题定义新颖。
2. 方法简单、无需反向传播、基本无额外推理开销，可直接用于多种 MLLM 和视频。
3. 评测指标针对"名词应该亮、功能词不应该亮"设计，比直接套用分类解释指标更合理；应用面广。

**局限**：
1. 原文承认：只处理视觉输入，音频等模态未涉及；"解释模型决策"还有待扩展；受设备限制未测超大模型。
2. **只评合理性（像不像人类的定位），不评忠实性（是否反映模型真实计算）**——作者自己论证了忠实性测试在 MLLM 上难以实施，但这也意味着热力图可能"好看但不忠实"。
3. "估计因果推断"实际上是减去相关 token 激活图的线性近似，因果含义较弱；减法会降低整体响应强度，评测时需要额外处理。
4. 基础激活图依赖"视觉特征 × lm_head 权重"，隐含假设视觉 token 的表示已与输出词表对齐——而 IMA、Same Task 显示这种对齐在很多层并不成立。
5. 只回答"看哪里"，不回答"用了什么概念"。
6. Obj-IoU 依赖 NLTK 词性标注和掩码名称的词形匹配，数量词、介词等被排除，覆盖有限。

**未来工作**：
- 原文：扩展到音频等其他模态；进一步解释模型决策；应用于开放词表分割、检测、定位、异常检测、遥感、医疗等需要像素级激活的场景。
- 推断：研究 MLLM 可行的忠实性评测；从"区域"解释上升到"概念"解释。

**与本项目的关系**：
- TAM 明确承认"MLLM 的解释无法验证忠实性"，这正是内生可解释模型的最强卖点：在我们的模型里，每个输出词的 logit 可以精确分解到概念，概念再对应到视觉 token，忠实性由结构保证，无需扰动测试。
- 它的基础激活图（视觉特征 × 输出词权重）与 Steerling 的"概念 → logit"线性通路形式非常接近：我们可以做"视觉 token × 概念嵌入"的**概念激活图**，并直接复用它的 Obj-IoU/Func-IoU/F1-IoU 评测协议与之比较。
- "前文 token 干扰后文解释"的现象在块内双向注意力的 Steerling 中可能更复杂（同一块内 token 相互可见），需要在我们的解释中考虑。
- 空白 2（用内生模型作为事后方法的金标准测试床）在这里有了具体对象：可以在我们的模型上跑 TAM，检验它的热力图是否与真实概念贡献一致。

## [11] Learning Multimodal Dictionary Decompositions with Group-Sparse Autoencoders（ICLR 2026，Georgia Tech / Dolby，Kaushik, Barch, Fanelli）

**核心问题**：在 CLIP 这类图文已对齐的嵌入空间上训练 SAE，会学出"**分裂字典**"——大多数特征只对一种模态激活。于是配对的图像和文字在稀疏编码空间里完全不重叠，概念命名、跨模态检索、跨模态操控都会失效。

**方法**：
- **定义**：若任意两个不同模态嵌入的稀疏编码支撑集不相交，则字典是"模态分裂"的。
- **理论（定理 1）**：若配对嵌入内积 > c > 0，且存在一个分裂字典给出 K-稀疏非负分解，那么一定存在一个多 n 个元素的字典，给出 (K+1)-稀疏分解，并且所有配对的稀疏编码内积严格为正。→ 结论：分裂字典**不是线性表示假设的必然结果，而是标准 SAE 训练的隐式偏置**，可以纠正。证明用 Gram-Schmidt 构造。
- **MGSAE**：用配对的图文（或音频-文本）嵌入训练，共享编码器/字典（各模态有自己的预偏置），损失 = 两个模态的重建误差 + λ × **组稀疏损失**（L2,1 范数，鼓励配对编码的支撑集相同）；再加**跨模态随机掩码**（TopK 之前对两个模态施加同一个随机掩码，迫使它们从同一批坐标里选）。
- **新指标 MMS（多模态单义性分数）**：对某个神经元，取在两种模态上都激活的样本，用另一个独立编码器算它们的余弦相似度，按共激活强度加权平均；分裂字典的神经元得分为 0。

**实验设置**：CLIP ViT-B/16 + CC3M 图文对；LAION-CLAP（音乐微调版）+ JamendoMaxCaps 音乐-文本对（首次把 SAE 用于音频-文本联合嵌入）；K=32、字典 8192；附录加 SigLIP2、AIMv2、MS COCO、不同扩展倍数和 K；对比 TopK、BatchTopK、Matryoshka SAE。

**主要结果**：
- 同时对两种模态激活的神经元显著增多，死神经元显著减少；MMS 分数整体更高。
- 零样本分类（用稀疏编码代替原嵌入）：CIFAR-10 0.657 → 0.842，CIFAR-100 0.418 → 0.554，ImageNet 0.303 → 0.373（原始 CLIP 为 0.916 / 0.687 / 0.686）。音频：GTZAN 流派 0.376 → 0.705，NSynth 乐器 0.265 → 0.354。
- 案例：CelebA "金发"线性探针的概念分解中，MGSAE 找到"金发"并揭示与"女孩/女性"的伪相关；标准 SAE 做不到（因为概念命名依赖文本端，分裂字典的视觉特征命名不准）。
- 附录：在 CLAP 上干预"violin"神经元，检索结果从无小提琴逐渐变为以小提琴为主；扩展倍数影响小、K 越大对齐越好。

**优点**：
1. 问题定义清楚（分裂字典），并给出"多模态字典一定存在"的构造性证明，把现象归因于训练偏置，理论与方法衔接紧密。
2. 方法简单（一个组稀疏正则 + 共享掩码），容易迁移；覆盖图文和音频-文本两类，还验证了多个编码器。
3. 提出了能同时衡量"语义性"和"多模态性"的 MMS 指标。
4. 通过概念命名 + 探针分解的案例，说明模态对齐直接影响可解释性分析的正确性。

**局限**：
1. 原文提到：多于两个模态、以及大量未配对数据的情况尚未研究（留作未来工作）。
2. 只研究**双塔对比模型的最终嵌入**（CLIP/CLAP 的单个向量），不涉及生成式 MLLM 内部逐 token、逐层的表示。
3. 需要配对数据；稀疏编码的零样本性能仍远低于原嵌入（ImageNet 0.373 vs 0.686），说明 SAE 分解丢失了大量信息。
4. 定理只证明存在性（且每对样本加一个字典元素，构造方式并不实用），不保证训练能找到该字典。
5. 概念命名依赖 CLIP 文本相似度和固定词表，命名本身有偏差；干预只有定性例子。

**未来工作**：
- 原文：扩展到多于两个模态；在大量未配对数据 + 少量配对数据的场景下只对配对样本施加组稀疏损失。
- 推断：把组稀疏思想用于生成式 MLLM 内部表示；与因果干预评测结合。

**与本项目的关系**：
- 这篇与我们的核心风险**最直接相关**：它证明了"用共享字典解释多模态表示时，默认会学成分裂字典"，而且这是训练偏置、可以纠正。Steerling 的概念头如果直接接入视觉 token，很可能出现类似现象：视觉 token 只激活少数"视觉专属"的发现概念或全部进入残差，而不激活已命名的文本概念。
- 方法可直接借鉴：在我们的训练中，对**图像 token 与其描述文本 token 的概念激活**施加组稀疏损失（鼓励二者激活同一批概念），并使用共享掩码。这可以作为"视觉信息进入概念通道"的具体方法之一。
- MMS 指标、"同时对两种模态激活的概念数 / 死概念数"可以直接作为我们的评测指标。
- 它还支持音频-文本，为后续扩展到音频（包括抑郁场景）提供参考。

## [13] A Comprehensive Information-Decomposition Analysis of Large Vision-Language Models（ICLR 2026，东京大学 / 微软亚洲研究院，Xiu, Luo, Nakayama）

**核心问题**：准确率只说明 LVLM 答对了多少，不说明它**靠什么答对**——是真正融合了图文，还是主要依赖语言先验？现有可解释性研究要么过于微观（只看某个模态），要么用缺乏理论基础的临时指标。

**方法**：
- 用**部分信息分解（PID）**把"视觉特征 X1、语言特征 X2 关于模型预测 Y 的互信息"分解为四项：冗余 R、视觉独有 U1、语言独有 U2、协同 S，称为"信息谱"。
- 采用 Liang et al. (2023) 的 BATCH 估计器（用神经网络参数化联合分布，Sinkhorn 算法满足边缘约束），并做三处适配：X1/X2 取视觉/文本 token 嵌入的平均池化；**单模态条件分布**通过把另一模态的整段嵌入替换为按数据集统计量采样的高斯噪声获得；候选答案总置信度低于阈值 τ=0.3 时替换为均匀分布；P(Y) 用软聚合而非 argmax 计数。
- **只适用于有限答案集**：限定为多选 VQA（A/B/C/D）。不使用标签，所以 PID 描述的是模型行为而非正确性。
- 三个分析维度：26 个模型（0.5B–90B，11 个家族）× 4 个数据集；用 logit lens 做逐层 PID；复现 LLaVA-1.5 两阶段训练并追踪 8 个检查点。

**实验设置**：MMBench（通用推理）、POPE（幻觉）、Reefknot（幻觉/关系）、PMC-VQA（医学）；每个数据集按 3:1 划分用于训练估计器和估计 PID；8×A100。另做"移除图像"的干预验证。

**主要结果**：
1. R 和 U1 始终很小，主要由 S 和 U2 区分。任务分成两种模式：**协同驱动**（MMBench、POPE，S 高）和**知识驱动**（Reefknot、PMC-VQA，S 低、U2 高，准确率低 20–30%）。
2. 协同驱动任务上，S 与准确率的 Spearman 相关约 0.75（p<0.001），总互信息反而不稳定；知识驱动任务上 U2 更能预测准确率。
3. 移除图像后的准确率下降与 S 强相关（MMBench 0.81、POPE 0.74），验证 S 反映了真实的视觉依赖。
4. 模型家族有稳定的两种策略：**融合型**（InternVL、Qwen-VL，高 S）vs **语言型**（Gemma3、Cambrian，高 U2），跨任务保持不变；同一家族内，规模带来的准确率提升主要伴随 S 增加，而不是 U2 增加。
5. 逐层：S 在中后层出现并达峰，接近输出时回落，最后一层再次突增；U2 逐层累积，在倒数第二层达峰后骤降——"三阶段"模式（InternVL3-2B 例外；Qwen2.5-VL-7B 和 InternVL3-8B 的 logit lens 无意义，未分析）。
6. LLaVA-1.5 训练中，对齐预训练阶段 S 和 U2 都很低，**视觉指令微调阶段才出现融合**；7B 的 S 增长更多，13B 的 U2 增长更多。
7. 附录：池化方式和 τ 对结论几乎无影响；案例显示同样答对，Gemma3 是"用视觉纠正错误的语言先验"，而 Qwen/Llama 是"产生协同"。

**优点**：
1. 理论基础扎实（PID），把"靠视觉还是靠语言"量化为可比较的数值，超越只看准确率。
2. 规模很大（26 个模型、4 个数据集、逐层、训练过程三个维度），并用"移除图像"干预验证指标的含义。
3. 不需要标签和改动模型，模型无关；稳健性消融完整，代码开源。
4. 提出"融合型 vs 语言型"家族策略、"指令微调才学会融合"等可操作的结论，并建议可把 PID 作为训练辅助目标。

**局限**：
1. 原文承认：只适用于离散答案空间，不覆盖开放式生成；单模态探针（噪声替换）是近似，不是真实单模态输入；PID 是相关性分析，不是因果机制。
2. **单模态视觉探针天生偏置**：多选题的选项在文本里，去掉文本后模型只能输出均匀分布（附录案例中 P(Y|X1) 几乎总是 0.25），导致 U1 恒接近 0——"视觉独有信息很少"很可能是探针设计造成的。
3. X1、X2 取平均池化的嵌入，丢失了 token 级和空间信息；PID 只在"模态"粒度上，不涉及概念。
4. 逐层分析依赖 logit lens，而对部分强模型 logit lens 不给出有意义的中间预测，只能跳过。
5. 训练动态只在 LLaVA-1.5 一个家族上复现。

**未来工作**：
- 原文：开发适用于生成式设置和更多模态的 PID 估计器与输出编码，探索其他单模态探针；在扩展规模和指令微调时把 (U1, U2, S) 作为诊断信号，甚至作为平衡融合与语言先验的**辅助训练目标**；构建明确需要高协同或能隔离语言先验的基准。
- 推断：把 PID 细化到概念级（哪些概念贡献了协同）。

**与本项目的关系**：
- 它发现"融合能力主要在视觉指令微调阶段才学到，对齐预训练阶段几乎没有"。对我们意味着：只训练投影层（Stage 1）可能不足以让视觉信息真正进入 Steerling 的概念通道，**Stage 2（LoRA/指令微调）是关键**；我们的 go/no-go 诊断应放在 Stage 2 之后再下结论，或至少在两阶段分别测量。
- 协同 S 与"移除图像后的性能下降"强相关，这给了我们一个模型无关的外部标尺：可以检验"概念通道中的视觉贡献"是否与 S 一致。
- 医学数据（PMC-VQA）落在"知识驱动"模式，协同很低——提示在医学场景里，模型可能主要靠语言知识而非视觉。这对后续抑郁/医学方向是一个警示：需要专门验证非文本模态是否真的被使用。
- 它建议把 PID 作为辅助目标，与我们"训练时就让视觉进入概念空间"的思路方向一致，可作为相关工作引用。

## [14] Are Emotion and Rhetoric Neurons in LLM? Neuron Recognition and Adaptive Masking for Emotion-Rhetoric Prediction Steering（ACL 2026 长文，武汉大学等，Zheng et al.）

**核心问题**：LLM 的情绪和修辞能力通常靠提示工程或微调在输出层面优化，缺少神经元层面的因果解释和精细控制；已有"情绪神经元"研究没有涉及修辞，也没有研究二者的关系；而且常用的神经元验证方法（置零、均值替换）在情绪/修辞任务上会出现**反直觉现象**——屏蔽"相关神经元"后准确率不降反升。

**方法**（模型：Llama-3.1-8B-Instruct，只看 FFN 神经元，参数全部冻结）：
- **神经元识别**：统计每个神经元在各情绪（6 类：喜、悲、怒、惧、惊、厌）/修辞（4 类：隐喻、夸张、幽默、讽刺）句子上的激活频率，归一化成概率分布后计算熵，取熵最低的 1% 作为情绪/修辞神经元。
- **自适应掩码**：按"目标句 vs 非目标句"的平均激活差 D_i 取前 10% 作为核心神经元；不是置零，而是按系数 α 做**衰减掩码**；再加**反馈优化**——若掩码后准确率没有下降，就提高选择阈值和 α，直到下降为止（作者说明只在开发集上调参，测试集只用一次）。
- **神经元操控**：对非目标句子，把核心神经元的激活按系数 β 推向目标类别句子的平均激活，看模型是否改判为目标类别。
- **修辞辅助情绪识别**：把某修辞（如隐喻）神经元的平均激活以系数 ω 加到同层情绪神经元上。

**实验设置**：DailyDialogue（情绪）、TroFi（隐喻）、HYPO（夸张）、ColBERT（幽默）、IAC-v2（讽刺）；跨数据集测试 IEMOCAP、LCC、HYPO-L、FunLines、MUStARD；指标为准确率。

**主要结果**：
- 在 8B 模型上，情绪和修辞神经元集中在**顶层**（前 25 层激活很低，之后急剧上升）；70B 模型的情绪神经元呈"顶层 + 底层"两端分布。
- 置零掩码常导致准确率上升（作者推测是功能互补的神经元簇接管）；均值替换多数任务下降不明显；自适应掩码在原测试集和 5 个跨数据集上都稳定降低准确率。
- 全层掩码影响最大，其次是顶层掩码 → 功能依赖跨层协同，且集中在上层。
- 操控：注入目标神经元特征后，非目标句子被判为目标类别的比例显著提高。
- 修辞神经元注入对多数情绪类别有正面作用（隐喻→恐惧、夸张→全部情绪、讽刺→悲伤），幽默会削弱快乐和惊讶。

**优点**：
1. 首次系统研究"修辞神经元"及其与情绪神经元的关系，问题新颖；与情感计算直接相关。
2. 明确指出并实证了"置零/均值替换验证不可靠"的问题——这对所有做神经元/特征干预的工作都是重要提醒。
3. 识别 → 验证 → 操控 → 跨任务注入的流程完整，有跨数据集测试。

**局限**：
1. 原文承认：只覆盖 6 种基本情绪和 4 种修辞；操控使用静态功能向量，缺少依赖上下文的动态调整。
2. **验证方法存在循环性**：反馈优化会不断加大掩码强度直到准确率下降，"掩码导致准确率下降"几乎是被调出来的，不能独立证明这些神经元特异地承担该功能（缺少"掩码同样数量的随机神经元"的对照）。
3. 操控是把激活推向目标类别的**平均激活**，本质上接近直接注入类别信号，改判比例提高并不意外；没有检验对其他能力的副作用。
4. 修辞神经元"辅助"情绪识别的机制没有解释（为什么在同一神经元索引上相加有意义）；增益幅度与统计显著性描述不足。
5. 单神经元层面，未处理多义性（神经元同时编码多个概念）问题。
6. **纯文本**，只研究一个模型家族。

**未来工作**：
- 原文：扩展到复杂情绪状态和更多修辞形式；设计依赖上下文的动态操控策略。
- 推断：加入随机神经元对照；扩展到语音/面部等多模态情绪；用 SAE 特征替代单神经元。

**与本项目的关系**：
- 与后续**抑郁/情感场景**直接相关：它表明 LLM 中存在对情绪有选择性的内部单元，并且集中在上层——Steerling 的概念头恰好在最后一层，其中已有的 tone（441 个）等概念可能正对应这类信息，可在 DAIC 文本上检查。
- 它揭示的"置零掩码反而提高准确率"现象，说明**在事后找到的单元上做干预很不可靠**；而 Steerling 这类内生模型的概念干预是直接作用于通向输出的线性通路，理论上可避免"其他通路补偿"——但之前那篇临床 steering 失败的论文提示实际效果仍需验证。这两篇可以放在一起，作为我们"内生概念的干预是否可靠"评测设计的参考：必须包含随机概念对照。
- 其"修辞增强情绪"的思路提示：在抑郁评估中，语言风格类概念（如否定、绝对化表达）可能与情绪状态概念存在类似的协同，可作为后续可解释分析的一个角度。

## [15] Inside-Out: Measuring Generalization in Vision Transformers Through Inner Workings（CVPR 2026，特拉华大学 / 乔治梅森大学，Peng, Ma, Yao, Peng）

**核心问题**：部署时目标域没有标签，现有的无标签代理指标（置信度、"准确率在一条线上"、熵、特征秩等）只看模型输出，存在欠定（ID 准确率相同但 OOD 差异很大）和过度自信问题。能否用模型内部机制（电路）预测泛化性能？

**方法**：
- **电路定义**：把 ViT 表示成计算图（每个注意力头、每个 MLP 为节点），电路是边权重函数：去掉某条边后模型输出分布的 KL 散度（均值消融，无需标签）；用 EAP-IG 高效近似（附录 G 在 Color-MNIST、Waterbirds、ImageNet 上比较了 5 种电路发现方法后选定）。
- **部署前模型选择**：把边权重按"源层 → 目标层"聚合成层间依赖矩阵；用 CCA 发现"通用泛化模式"——**依赖深层的连接与泛化正相关，依赖浅层（捷径）的连接负相关**，尤其是指向输出的边。据此定义**依赖深度偏置 DDB** = 深层源 / 浅层源的依赖强度之比（三个变体：全局、深层、输出）。
- **部署后性能监测**：同一模型在不同分布上电路的整体拓扑保持稳定，但分布偏移越大"重连"越多；定义**电路偏移分数 CSS** = 测试分布电路与 ID 基准电路的距离（向量距离：L2、余弦、秩相关；图距离：拉普拉斯谱、NetLSD、Jaccard）；用 39 种合成腐蚀/风格化构造校准集来设定报警阈值。

**实验设置**：部署前：PACS、Camelyon17（病理切片，按医院划分）、Terra Incognita，共 26 个"训练域 → 测试域"任务，每个模型库 72–144 个 ViT（5 种预训练权重 × 超参网格）；部署后：PACS、Camelyon17（34 个 OOD 切片域）、FMoW、ImageNet（-C/-v2/-Sketch，27 个域）。基线包括 ID 准确率、锐度、平均置信度、熵、MDE、RankMe、α-ReQ、ATC。

**主要结果**：
- DDB_out 与真实 OOD 性能的平均相关 0.766，比最佳基线高 13.4%；训练过程中 DDB_out 与 OOD 准确率同步变化（泛化好的模型从 2.6 升到 4.1，差的模型停在约 −0.9）。τ=0.3 最优。
- CSS（秩相关版）平均相关 0.811，比最佳基线高 0.341（约 34%）；向量型优于图型。
- Camelyon17 上"静默失败"报警 F1 比基线高约 45%（在临床可接受的 0.8–0.9 性能阈值范围内）。
- 不同分布偏移有不同的电路变化模式：FMoW 全层变化，Camelyon17 集中在深层。

**优点**：
1. 把机制可解释性从"解释"转向"预测"，提出了明确的实用场景（部署前选模型、部署后监测），且无需目标域标签。
2. 实验规模大（大量模型库、多个真实分布偏移数据集，含医学病理），并系统比较了电路发现方法本身的忠实度和效率。
3. "依赖深层特征 → 泛化好；依赖浅层捷径 → 泛化差"的发现直观且有训练动态支持。

**局限**：
1. 原文承认：电路发现计算量大，适合一次性模型选择，难以用于实时监测。
2. 只研究**纯视觉 ViT 分类器**，不涉及多模态或生成模型。
3. 电路基于均值消融和 EAP-IG 近似，而附录自己的基准显示不同方法忠实度差异明显；CCA 模式分析容易过拟合（作者自己也说只能定性）。
4. CSS 需要 ID 基准电路和合成腐蚀校准集，阈值对校准集的代表性敏感。
5. 解释停留在"层间依赖结构"，没有语义层面的内容。

**未来工作**：
- 原文：开发更高效的电路发现算法；**直接优化这些电路指标，在训练中鼓励形成更可泛化的机制**。
- 推断：扩展到多模态和生成模型；把电路指标与概念级解释结合。

**与本项目的关系**：相关度较低，但有两点可借鉴。
1. "用内部机制预测模型可靠性"的思路可以迁移：在内生可解释模型里，**概念占比（known/discovered vs ε）或视觉贡献的概念分布**可能同样可以作为无标签的可靠性/幻觉预警信号，这是一个可做的下游应用。
2. "依赖深层 vs 浅层捷径"的发现，与 Info Flow、Same Task 的层级结论可以放在一起讨论：视觉信息在哪一层进入概念通道，可能影响模型的泛化。

# 跨论文的关键发现（对本项目的证据链）

1. **视觉与文本表示天然分离**：IMA（不同窄锥）、SAE-V（文本训练的字典解释不了视觉）、Group-sparse SAE（标准训练必然学成分裂字典）。
2. **但这种分离可以被训练纠正**：IMA（训练映射模块会自发提高对齐）、Group-sparse SAE（组稀疏 + 共享掩码显著增加多模态概念）、USAE（共享编码迫使不同来源对齐）、CoX-LMM 附录 G（深层视觉 token 本身有可用文字解释的概念）。
3. **视觉信息的作用集中在中低层，对齐偏晚**：Info Flow（低层整图、中层局部，高层可丢弃图像 token）、Same Task（对齐太晚导致图像任务更差）、PID（协同在中后层出现）。→ 与 Steerling 概念头只在最后一层存在结构性张力。
4. **融合能力主要在指令微调阶段学到**：PID（LLaVA 对齐预训练阶段协同几乎为 0）。
5. **MLLM 的事后解释无法验证忠实性**：TAM 明确放弃忠实性评测；VPS 评测有循环性；Emotion Neurons 的验证需要调参到"生效"为止；MICLIP 在 LLaVA 上效果很小。
6. **事后干预不可靠**：Emotion Neurons（置零掩码反而提高准确率）、MICLIP（单神经元干预幅度小）；再加上此前找到的 Basu et al.（Steerling 原版临床 steering 与随机无差异）。

# 研究空白（基于全文精读修订）

- **空白 1（主线）：内生可解释的生成式多模态模型**。文本有 Steerling/CB-LLM，CLIP 有 MM-CBM，生成式 MLLM 空白。

- **空白 3（评测）：MLLM 解释的忠实性金标准**。内生模型的概念贡献是精确已知的，可作为测试床评估 TAM、VPS、SAE 等事后方法。

## [16] Multimodal Concept Bottleneck Models（MM-CBM，NeurIPS 2025 Mechanistic Interpretability Workshop，UCSD，Shi, Yan, Oikarinen, Weng）

**核心问题**：概念瓶颈模型（CBM）有两个缺陷：(1) 最后是线性分类器，只能做固定类别，不能接受自由文本；(2) **信息泄漏**——当概念层维度足够大时，即使概念层是随机投影，线性分类器也能拟合出原始预测，概念层的约束作用失效。

**方法**：
- 在 CLIP 上加**两个概念瓶颈层**：图像 CBL 把图像嵌入映射到概念空间，文本 CBL 把任意文本映射到同一概念空间；推理时**完全在概念空间内**算图文相似度，不再有线性分类器。
- 概念集：用 GPT-3.5 为每个类别生成候选概念（特征、常见共现物、上位词），按长度、与类名相似度、冗余度过滤；零样本场景用 SpLiCE 的通用概念集。
- 概念标签：图像端用 OWLv2 开放词表检测器判断概念是否出现（二值）；文本端用 all-mpnet-base-v2 计算类名描述与概念的语义相似度（连续值，沿用 CB-LLM 的自动概念打分）。
- 损失：可解释性损失（图像 BCE + 文本负余弦）与分类损失按 λ=0.2 加权；相似度只取**前 n 个**逐元素乘积之和（NEC=5，有效概念数），并对概念向量做 ReLU 非负化。
- 附录：无标签时可用 CLIP 的预测做知识蒸馏；用 Llama-3.2-Vision 为每类生成 50 条以上描述增加文本多样性。

**实验设置**：CIFAR-10/100、ImageNet、Food-101、CUB、Oxford Pets、DTD；另在 CC12M 上训练测泛化；对比 LF-CBM、LaBo、LM4CV、VLG-CBM 和黑盒 CLIP ViT-L/14。

**主要结果**：
- NEC=5 条件下（CLIP-RN50）：平均 70.2，略高于 VLG-CBM（68.6），ImageNet 70.2 vs 59.7。
- 与黑盒 CLIP 比：微调场景差距多在 1–3 点（DTD、CUB 差 9–10 点）；零样本场景差距较大（CUB 62.3 → 39.2，Pets 93.5 → 80.1，ImageNet 75.3 → 67.4）。
- ReLU 非负化使视觉激活的 L1 范数缩小约 20 倍（更稀疏），准确率不降。
- 以 LLaVA-1.5 和 Llama-3.2-Vision 互相当裁判，MM-CBM 的解释分别在 88.7% 和 65.8% 的情况下被认为"包含更多有信息量的视觉概念"。
- 人工干预：把错误激活的概念置零可纠正错误（100 个样本子集上提升 3%）。
- 其他主干：SigLIP 可提升（82.1 → 84.8），但 SigLIP2 大幅下降（83.1 → 70.1）。
- 检索案例：支持标签、概念、组合、分布外、抽象五类查询。

**优点**：
1. 真正的"内生可解释 + 多模态"：图文都进入同一个有名称的概念空间，推理全程透明，并从结构上消除线性分类器带来的信息泄漏。
2. 通过文本 CBL 支持自由文本查询，突破固定类别限制，可做零样本分类和检索。
3. 实现简单、效率高（比精心提示的 VLM 解释快约 1000 倍）。

**局限**：
1. **不是生成模型**：只能做图文相似度（分类、检索），不能生成文本，不涉及 VQA 或 LLM。
2. 概念标签依赖 OWLv2 检测结果和句向量相似度，是有噪声的弱监督；附录的人工干预分析也显示错误来自句向量模型带来的语言偏差。
3. 零样本性能损失明显，更换主干（SigLIP2）时性能大幅下降，稳定性存疑。
4. 解释质量由 VLM 当裁判评估，且问题是"哪个描述包含更多视觉概念"——对 CBM 式的概念列表天然有利；没有人工评估，也没有忠实性的定量检验。
5. 概念集规模小（每个数据集 141–4553 个），且依赖 GPT-3.5 生成；只取前 5 个概念可能丢失信息。
6. Workshop 论文，实验深度有限，无消融显示两个 CBL 各自的必要性。

**未来工作**：
- 原文（结论）：应用于图像检索、图像描述、视觉问答等更广的多模态任务。
- 推断：扩展到生成式模型；用人工标注的概念做更可靠的监督；解决更换主干时的性能不稳定。

**与本项目的关系**：
- **最接近的已有工作**，必须在论文中正面比较。区别很清楚：它是判别式 CLIP 层面的双塔概念瓶颈；我们是**生成式**模型，概念分解作用于每个生成 token 的 logit，而且使用 Steerling 预训练好的 33K 通用概念，而不是按数据集由 GPT 生成的小概念集。它自己的未来工作列出了 VQA 和图像描述，正好是我们要做的。
- 可借鉴：用开放词表检测器（OWLv2）为图像自动生成概念标签，作为视觉概念监督的来源——可以把 COCO 等数据上的检测结果映射到 Steerling 的概念 ID；"去掉线性分类器以杜绝信息泄漏"的思路，对应我们需要控制残差 ε 的大小。

## [17] Concept Bottleneck Large Language Models（CB-LLM，ICLR 2025，UCSD，Sun, Oikarinen, Ustun, Weng）

**核心问题**：概念瓶颈模型在图像分类上已很成熟，但在 NLP 中只有少数工作（TBM、C³M），而且只能做小数据集的文本分类、依赖 GPT-4 大量打标签，从未扩展到文本生成。能否把任意预训练 LLM 改造成内生可解释的模型，并覆盖分类和生成？

**方法一：分类版（5 步）**
1. 用 ChatGPT 为每个类别生成概念（每类一次查询，SST2 208 个、Yelp 248 个、AGnews 216 个、DBpedia 476 个）。
2. **自动概念打分（ACS）**：用句向量模型 all-mpnet-base-v2 计算文本与每个概念的相似度作为伪标签，不调用 LLM。
3. **自动概念校正（ACC）**：负分置零，且不属于该样本类别的概念分数置零（利用"概念按类生成"的对应关系）。
4. 训练骨干 + 概念瓶颈层（CBL），用 cos³ 相似度对齐伪标签。
5. CBL 输出过 ReLU，再训练带弹性网正则（强稀疏）的线性分类层。

**方法二：生成版**
- CBL（k 个概念神经元，ReLU）与**无监督神经元层**并联，拼接后经最后一层线性层输出词表 logits；损失 = 概念交叉熵 + 下一 token 交叉熵 + 弹性网正则。
- **对抗解耦模块**：无监督层输出接一个线性分类器预测概念；分类器最小化概念分类误差，无监督层最大化该分类器的预测熵（让它"猜不出概念"），迫使概念信息只走 CBL。仅训练时使用。
- 干预：推理时把某概念神经元设为 100、其他为 0，通过最后一层线性权重直接影响相关 token。

**实验设置**：分类用 RoBERTa-base、GPT2、Gemma2-2B；生成用 Llama3-8B（附录加 Llama2-13B、Mistral-7B）；数据集 SST2、Yelp Polarity、AGnews、DBpedia（生成实验中后三者缩减到 10 万样本）；Amazon MTurk 人工评测；案例：概念遗忘、毒性检测与控制。

**主要结果**：
- 分类（RoBERTa）：加 ACC 后 SST2 94.1 / Yelp 98.1 / AGnews 94.5 / DBpedia 99.3，与黑盒微调（94.6 / 97.8 / 95.1 / 99.2）基本持平；ACC 平均提升 3.5 点。ACS 打标签 1.6 小时，而 LLM 打标签 1000 个样本就需 8.8 小时。
- 人工评测：激活忠实度平均 4.12 vs 基线 2.75；贡献忠实度 50% 更偏好 CB-LLM、28.6% 偏好基线。
- 概念遗忘：去掉"价格过高"概念后 2726 个样本由负转正，NLI 模型确认其中 79% 确实含该概念。
- 生成（Llama3-8B）：概念检测准确率与黑盒微调分类器相差 <1%；**可控性**（无提示生成 100 token，设定目标概念后被 RoBERTa 分类器判为目标类的比例）0.76–0.95，去掉对抗模块后降到 0.21–0.69（DBpedia 接近随机）→ 对抗解耦是可控性的关键；困惑度与黑盒相近，但 SST2 上明显更高（116 vs 85）。
- 毒性聊天机器人：4 个可解释神经元（良性/有害查询、良性/有害回复），毒性检测准确率 0.9996，可控性 0.914。

**优点**：
1. 首个把概念瓶颈扩展到大规模文本分类和**自回归生成**的框架，且几乎不损失性能；全自动、成本低（不依赖大量 LLM 打标签）。
2. 生成版的"概念层 + 无监督层 + 对抗解耦"是处理"概念覆盖不全"问题的直接方案，并用消融证明了对抗模块对可控性的必要性。
3. 有人工评测、概念遗忘、毒性控制等应用验证，代码开源。

**局限**：
1. **生成版的"概念"极粗**：直接使用数据集的类别标签作为概念（AGnews 只有 4 个：世界/体育/商业/科技；毒性案例只有 4 个神经元）。绝大多数生成所需信息仍在不可解释的无监督层里——"可解释"只覆盖了主题/类别这一维。
2. 概念检测评测的是"最高激活的概念神经元是否等于类别"，本质是分类准确率；可控性是在**无提示**生成上测的，没有检验在真实对话/有提示场景下的效果和副作用。
3. 分类版的 ACC 用真实类别标签把"不属于该类的概念"清零，训练时概念标签含有类别信息，存在向概念层泄漏标签的风险；概念由 ChatGPT 生成、由句向量打分，质量依赖这两个模型。
4. 人工评测只与 TBM&C³M 的弱化复现（Llama3-8B 打标签、1000 个样本）比较，且有 21% "同样好"；评测的是合理性而非因果忠实性。
5. 纯文本；每个任务需单独训练一个模型，不是通用基座。

**未来工作**：
- 原文没有单独的局限/未来工作章节（正文结论只总结贡献）。
- 推断：扩展到更细粒度、跨任务的通用概念集；在有提示的真实对话中评估可控性；扩展到多模态。

**与本项目的关系**：
- 这是 Steerling 之前"内生可解释生成式 LLM"的代表作，也是 MM-CBM 的同组前作。对比很清楚：CB-LLM 的生成版只有数个任务相关概念 + 大量无监督神经元；**Steerling 则在预训练阶段就学了 33K 个通用已命名概念 + 10 万个发现概念**，覆盖面高出几个数量级。这正是我们选择基于 Steerling 而非 CB-LLM 的理由，可以写进动机。
- 其**对抗解耦**思想（让无监督通道"猜不出概念"）直接对应我们的核心风险：视觉信息漏进残差 ε / 发现概念。可以借鉴为：让残差 ε 上的一个探针无法预测图像中的物体概念，从而迫使视觉信息走已命名概念通道。
- 其"设置概念神经元 → 检查生成内容是否变成目标类别"的可控性评测协议，可以直接迁移为多模态版本（设置视觉概念 → 检查描述是否随之改变）。

## [18] Concept Bottleneck Generative Models（CBGM，ICLR 2024，Genentech / Prescient Design / NYU，Ismail, Adebayo, Corrada Bravo, Ra, Cho）

> 这篇的两位主要作者（Ismail、Adebayo）正是 Steerling 的作者，是 Steerling 的直接前身。

**核心问题**：生成模型难以解释和可靠地操控。现有做法（事后用简单模型探测表示、强制解耦、在低维投影里找方向）都不能保证模型的输出真的依赖于人类可理解的特征。能否把"概念瓶颈"从分类模型推广到生成模型？

**方法**：
- 在生成模型内部插入一个**概念瓶颈（CB）层**，把模型分成三段：CB 前网络、CB 层、CB 后网络。插入位置：VAE 解码器第一层、GAN 生成器输入（StyleGAN 放在映射网络之后）、扩散 U-Net 的中间块之后。
- CB 层基于概念嵌入模型（CEM）：每个概念有"激活/未激活"两个嵌入，由概率网络预测概念概率 ĉ_i，最终嵌入是二者按 ĉ_i 的加权；**额外增加一个"未知概念"嵌入**，因为预定义概念不可能覆盖生成所需的全部信息。
- 损失 = 任务损失 + α·概念损失（BCE）+ β·**正交损失**（让未知概念嵌入与已知概念嵌入的余弦相似度趋于 0，防止未知通道"复制"已知概念）。
- 干预：推理时把某个概念概率替换为想要的值，即可操控生成。
- 附录：支持连续变量和类别变量；**只用约 20% 样本有概念标注即可达到全标注的可控性**。

**实验设置**：CelebA（40 个属性）、CUB（312 个概念）、FFHQ 1024²（8 个概念）、LAION 美学子集（155 个概念：艺术风格、名人、虚构角色）、Color-MNIST；对比 CGAN、ACGAN、分类器引导/无分类器引导扩散、CVAE。可控性指标：先生成概念"不存在"的样本（由 ≥98% 准确的分类器判定），干预"打开"该概念后，被判为"存在"的比例。

**主要结果**：
- 可控性：CB-GAN 在 CUB/CelebA-8/CelebA-40 上为 21.3/25.6/23.1%，而 ACGAN 为 18.5/9.2/1.2%；CB-Diffusion 14.8/13.8/12.6% vs 无分类器引导 2.7/7.2/5.1%；CB-VAE 10.7/16.3/15.5% vs CVAE 1.2/5.9/5.3%。概念数从 8 增到 40 时，条件生成方法性能大幅下降，CB 模型基本不变。
- 生成质量：FID 与无约束模型相当；可以扩展到 StyleGAN2 1024² 和 155 个概念的扩散模型（240 V100 GPU 小时）。
- 消融（CB-GAN）：去掉概念损失可控性 25.6 → 11.0，去掉正交损失 → 19.9，去掉未知嵌入 → 16.5 且 FID 恶化到 44.1。
- 调试：用随机概念标签训练的模型，概念验证准确率停在随机水平，可据此判断模型是否学到了某概念。

**优点**：
1. 首次把概念瓶颈系统地引入三大类生成模型，且与模型家族无关。
2. "已知概念 + 正交的未知概念"的设计正面承认了生成任务中概念不完备的问题，并用消融证明了其必要性——这是 Steerling "known + discovered + ε" 结构的直接前身。
3. 概念数增加时可控性不下降，这一点明显优于条件生成方法；少量标注即可工作。

**局限**：
1. 原文承认：需要训练集带预定义的概念标注；只在图像任务上验证，"迁移到文本时概念应该是什么"是开放问题（后来由 Steerling 回答）。
2. **绝对可控性不高**：最好的 CB-GAN 也只有约 25% 的样本在干预后成功出现目标概念，扩散模型约 13–15%。
3. CB 后网络是非线性的，概念概率只能说明"哪些概念被激活"，不能像 Steerling 那样把输出精确分解为各概念的贡献；"解释"主要靠查看概率最高的前几个概念，属于定性展示。
4. 作者承认概念泄漏仍可能存在，正交损失只约束已知与未知两组之间，不约束已知概念之间。
5. 概念数量级只有几十到几百。

**未来工作**：
- 原文：作为给大规模基础模型加入内生可解释组件的"垫脚石"；探索文本场景中概念应如何定义。
- 推断：减少对概念标注的依赖；更大规模的概念集；让概念对输出的贡献可精确分解。

**与本项目的关系**：
- 这是 Steerling 的"祖先"，读它能更清楚 Steerling 的设计动机：未知概念通道 + 正交约束 → 演变为 Steerling 的"发现概念 + 残差 ε"。它的消融（去掉正交损失可控性下降、去掉未知通道质量崩溃）说明：**已知通道与未知通道的信息分配，直接决定可控性**。对我们来说，视觉信息进入哪个通道（已知概念 / 发现概念 / ε）就是同一个问题，可以借鉴正交约束来防止视觉信息被"未知通道"吸走。
- 它自己把"迁移到其他模态/文本"列为开放问题，Steerling 解决了文本；我们做视觉，正好是这条线的自然延续——可以在论文中把这条线索（CBGM → Steerling → 本工作）写成清晰的发展脉络。
- "20% 标注即可"的结论对我们有用：视觉概念监督不需要全量标注，COCO 等数据的一部分检测标签即可。

## [19] The Standard Interpretable Model: A general theory of interpretable machine learning to deductively design interpretable methods using Lagrangian mechanics（SIM，arXiv 2606.12289，2026 年 6 月，IBM Research / USI / 剑桥等，Barbiero et al.）

> 阅读说明：51 页。正文（第 1–7 节）全部精读；附录 A–E 主要是约束与运动方程的逐步数学推导，我核对了其结构与结论，没有逐行复算每个推导。

**核心问题**：可解释性研究缺少"能**演绎地**推导出方法"的一般理论，导致文献碎片化、评测不一致、方法难以比较。能否像物理学用对称性建立标准模型那样，为可解释机器学习建立一个统一理论？

**方法（理论框架）**：
- 把任何 ML 模型写成一个拉格朗日量 L = T − V：V 是"可解释性地形"（误差 + 违反可解释性约束的程度），T 是参数动力学（决定用什么优化算法）。流程分六步：前提 → 对称性 → 约束 → 拉格朗日量 → 优化轨迹（最小作用量原理，离散化后即带动量的梯度下降）→ 或把约束直接"编译"进架构。
- 针对"具有有限词汇、语义映射和有限计算能力的使用者"，提出三条前提及对应的对称性：
  1. **共享概念语义**（对称性 I）：模型的概念分数只需与人类概念分数保持**相同的排序**（在单调变换下不变），而不必数值相等。推论：可解释性可传递但不可逆（"老师"能保留"学生"的区分，反之不行）。约束 I：成对排序违反率。架构 I：基于有序原型实例的概念映射。
  2. **预测只依赖概念**（对称性 II）：模型输出的梯度必须落在概念梯度张成的子空间里（在"投影到概念子空间"的操作下不变）。推论：满足它的模型天然可以通过概念操控。架构 II：概念瓶颈模型。
  3. **有界推理**（对称性 III）：概念到预测的组合函数必须属于人类可处理的假设类（用一个微分算子的解空间定义，如稀疏线性、低次多项式）。
- 两种实现途径：通过优化逐步逼近（只能保证局部、近似满足），或编译进架构（结构上保证、对分布外输入也成立）。

**实验设置**：
- 受控实验：比较普通 DNN、加约束损失的 DNN+L、把约束编译进结构的 DNN+A，分别验证三条对称性。
- 大模型应用：CLIP、Moondream2、Qwen2 对"红色程度"的排序一致性（对称性 I）；Qwen2.5 的 CoT 是否被预测依赖（对称性 II）；**Steerling-8B 的预测对已监督概念的依赖程度**（对称性 II）。

**主要结果**：
- 对称性 I：普通 DNN 的平均绝对误差最低，但排序违反率最高 → **拟合概念分数 ≠ 保持概念语义**，MAE 等常规指标不适合衡量可解释性。
- 对称性 II：优化约束只能在约束点附近实现对齐，编译进架构才能全局保证预测只依赖概念。
- 对称性 III：约束系数 λ3 可以像旋钮一样控制概念组合公式的复杂度。
- VLM 概念语义：三个模型对"哪张图更红"的判断彼此不一致、偏离真值，Moondream2 和 Qwen 甚至**交换图片顺序答案就变**（排序不自洽）→ 用预训练 VLM 自动生成概念标签（Label-free CBM 等的常用做法）有内在风险；用按红色程度排序的原型做最近邻匹配可无需训练修正。
- CoT：Qwen2.5 的约束违反分数始终 >0.8 → 下一个 token 的计算与 CoT 解释基本无关，CoT 不是可解释的解释。
- **Steerling-8B**：只保留前 K 个激活最高的已监督概念，把"概念化隐状态"的雅可比投影到概念雅可比的子空间；K≈500（约占已监督概念的 1.5%）时违反度降到 0.1 以下 → **预测确实主要由少量已监督概念中介**，与 CoT 形成鲜明对比。测试时只保留前 16 个概念，依赖结构精确符合理论曲线，但作者明确说明这会**损害预测性能**，不是实用设置。
- 系统比较：传统方法（特征归因、NAM、决策树）假设输入已是概念，违反对称性 I；SAE 的概念没有内在人类语义、对称性 II 只间接靠重建损失保证；原型网络概念无语义保证；CBM 对称性 I 过度约束（要求数值匹配），对称性 III 常被线性预测器过度约束。
- 工程：发布 PyTorch Concepts 库，内置 SteerlingModel。

**优点**：
1. 提供了统一、可演绎的理论框架，把损失、指标、架构、优化算法用同一套语言连接起来，并能系统地指出现有方法各缺哪条性质。
2. 区分"通过优化满足"与"通过架构保证"，并用受控实验说明前者只能局部成立——为内生可解释（架构保证）提供了理论依据。
3. 提出可证伪的评测框架：形式性质用解析或定量方法检验，与使用者相关的部分才需要用户研究。
4. 对 Steerling 做了独立的第三方检验，并与 CoT 对比，结论清楚。

**局限**：
1. 原文承认：三条前提/对称性是否穷尽了可解释性尚不清楚；约束推导能否自动化、能否高效实现有待研究；与几何、物理已有理论的联系尚未充分挖掘。
2. 大模型实验较轻量：VLM 实验只测"红色"一个概念、MNIST 图像；Steerling 实验只检验了对称性 II，**没有检验其概念语义（对称性 I）是否与人类一致**，也没有检验干预效果。
3. Steerling 实验基于局部雅可比（梯度子空间），衡量的是局部依赖；且只看已监督概念、用"概念化隐状态"近似下一 token 预测，排除了发现概念和残差的作用方式没有展开说明。
4. 理论框架较抽象，从前提到具体架构仍需大量人工设计；拉格朗日/最小作用量的类比在实践中最终落到"带动量的梯度下降"，实际增量有限。
5. 预印本（尚未见正式发表）。

**未来工作**：
- 原文：验证前提是否完备、是否需要更多对称性；自动化约束与架构的推导，提高效率；挖掘几何/物理理论在可解释性中的已有结果；**开发保证共享概念语义（对称性 I）的架构**、以及无需硬编码进结构的优化式约束方法（作者认为这是领域最大的空白）；在保持性能的前提下让概念依赖足够稀疏，便于人类检查。
- 推断：把 SIM 扩展到多模态输入。

**与本项目的关系**：
- **对 Steerling 有利的独立证据**：预测主要由约 500 个已监督概念中介，与 Basu et al. 的"临床 steering 与随机无差异"一起，构成对 Steerling"概念依赖是真的、但操控是否有效另当别论"的完整画像，应在论文中同时引用。
- 给出了我们论文可以直接使用的**形式化评测**：
  1. 对称性 II 检验（预测雅可比落在概念雅可比子空间的程度，随 K 变化）——**分别在纯文本输入和图像输入上测**，就能定量回答"视觉信息是否也走了概念通道"，这恰好是我们的核心问题。
  2. 对称性 I 检验（排序违反率）——可用于检验视觉概念激活是否与人类标注的程度排序一致（例如"红色程度""物体大小"）。
- 它指出"用 VLM 自动生成概念标签存在排序不自洽的风险"——提醒我们在用 MM-CBM 式的自动标注（OWLv2、VLM）做视觉概念监督时，需要检查排序一致性，或采用它提出的原型修正方法。
- 它把"保证共享概念语义的架构"列为领域最大空白；我们的工作（让视觉输入进入一个语义已固定的、共享的已命名概念空间）可以用这一框架来表述贡献：在多模态场景下同时满足对称性 I 和 II。

**对方法设计的新增启示**：
1. **对抗解耦**（CB-LLM）：训练一个探针从残差 ε（或发现概念通道）预测图像中的物体概念，残差通道对抗性地使其预测失败，迫使视觉信息走已命名概念通道。
2. **正交约束**（CBGM）：防止未知通道复制已知概念，对应控制视觉信息被发现概念/ε 吸走。
3. **弱监督来源**（MM-CBM + CBGM）：用开放词表检测器为部分图像生成概念标签，约 20% 标注即可；但需按 SIM 检查标签的排序一致性。
4. **核心评测**（SIM）：对称性 II 的雅可比子空间检验，分别在文本输入与图像输入上测量，直接量化"视觉是否走概念通道"。
